## 🎯 Overview

This project provides a complete data analytics pipeline analyzing **customer shopping behavior** from retail transaction data. It demonstrates best practices in **data cleaning, SQL analysis, Python processing, and business intelligence visualization** using real-world e-commerce data covering 3,900+ customer transactions.

### 📈 Key Metrics
- **3,900+** customer records analyzed
- **18** distinct features tracked per transaction
- **50+** geographical locations covered
- **25** product items across multiple categories
- **6** shipping types evaluated

## 📝 Sample Codes

### Find Top Revenue Generators
```sql
SELECT gender, SUM(purchase_amount) AS total_revenue
FROM customer
GROUP BY gender
ORDER BY total_revenue DESC;
```

### Identify Loyal Customers
```sql
SELECT customer_id, COUNT(*) as purchase_count
FROM customer
WHERE previous_purchases > 10
GROUP BY customer_id;
```

### Analyze Discount Effectiveness
```sql
SELECT 
    discount_applied,
    ROUND(AVG(purchase_amount), 2) as avg_purchase
FROM customer
GROUP BY discount_applied;
```
